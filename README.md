### # ESX Qbcore 大乐透彩票系统 README
## 资源介绍
##
本资源为 FiveM ESX Qbcore框架全自动大乐透彩票系统，全程无需管理员手动操作，系统自动倒计时、自动开奖、自动结算奖金、自动累加奖池、数据自动入库保存。支持手动选号、随机机选、手动中奖翻倍、封盘限购等完整彩票玩法，配套独立NUI可视化界面，适配所有ESX Legacy/QBcore服务器。

## 资源信息

- 适配框架：ESX Legacy QBcore

- 依赖插件：es\_extended、oxmysql

- 运行环境：FiveM Cerulean

- 资源类型：全自动娱乐玩法

- 操作按键：F5 打开界面 / ESC 关闭界面

## 配置参数说明

所有参数可自行修改，修改后重启资源生效

```Plain Text
Price = 500,             -- 单注彩票购买价格
StartJackpot = 10000,    -- 中奖后奖池重置初始金额
AddJackpot = 5000,       -- 无人中奖每期累加奖池金额
DrawInterval = 20,       -- 单期开奖总时长(秒)
MaxTickets = 5,          -- 单人每期最大购买注数
RandomWinChance = 10,    -- 机选专属中奖概率(百分比)
ManualWinMultiplier = 2, -- 手动选号中奖奖金倍率
NoBuyTime = 10          -- 开奖前封盘禁止购彩秒数
```

## 核心功能

- 双模式购彩：支持自定义4位数字手动购彩、系统随机机选购彩
- 中奖倍率机制：手动选号中奖奖金翻倍，机选为基础奖金
- 概率机制：机选自带独立中奖概率，可控调整中奖几率
- 自动奖池累计：当期无人中奖自动累加奖池，中奖后重置初始额度
- 多人平分奖金：多玩家同时中奖，自动平分当期总奖池
- 定时封盘功能：开奖前指定秒数禁止购彩，防止开奖作弊
- 数据持久保存：奖池数据自动存入数据库，重启服务器/资源不丢失
- 服务器日志记录：全程自动记录系统运行日志，包含玩家购彩记录、开奖号码、中奖信息、奖池变动记录，方便服主后台核查管理
- 全服公告提示：开奖结果、中奖玩家、奖金数额全服广播
- 界面实时同步：倒计时、奖池金额、已购号码实时刷新

## 数据存储机制

- 系统启动自动创建数据表 `lottery\_jackpot`，无需手动建表

- 仅奖池金额持久化存储，永久保存至数据库

- 玩家当期购彩记录为内存临时存储，每期开奖结束自动清空

- 资源关闭、服务器重启自动保存当前奖池数据

## 安装教程

1. 将资源文件夹放入服务器 `resources` 目录

2. 在服务器启动配置中添加：`ensure 资源文件夹名`

3. 确保 `es\_extended`、`oxmysql` 优先启动

4. 重启服务器，资源自动建表、初始化奖池，直接可用

## 玩家使用教程

- 按下 F5 打开彩票购买界面

- 手动购彩：输入4位纯数字号码，点击购买

- 机选购彩：直接点击机选按钮，系统自动生成号码

- 单期最多购买5注，封盘后无法继续购买

- 号码完全匹配开奖号码即可中奖，手动购彩奖金翻倍

## 常见问题排查

- **资源启动报错**：检查oxmysql、es\_extended是否正常加载且优先启动

- **无法购买彩票**：处于封盘倒计时、现金不足、已达单期购彩上限

- **奖池不保存**：检查数据库连接状态，确认数据表自动创建成功

- **界面不显示号码**：轻微同步延迟，重启界面或资源即可恢复

- **无开奖倒计时**：资源启动异常，检查控制台报错、排查资源冲突

## 二次开发说明

- NUI界面完全独立，可自由修改样式、配色、文案、布局

- 默认ESX现金收支，可拓展银行卡、代币、积分等货币体系

- 支持自定义通知样式、公告颜色、展示时长

- 概率、倍率、开奖时长全部可自定义配置

安全防外挂机制
- 服务端全校验机制：所有购彩、中奖逻辑全部服务端验证，客户端无法篡改数据，杜绝前端作弊
- 防重复购彩校验：单玩家单期号码唯一校验，禁止重复投注相同号码，杜绝刷票外挂
- 防重复中奖漏洞：单玩家每期只能触发一次机选保底中奖，杜绝无限中奖BUG
- 资金严格校验：服务端二次判断玩家现金余额，拦截虚假客户端发包购彩外挂
- 投注数量锁死：服务端严格限制最大购彩数量，客户端篡改数值无效
- 封盘服务端锁：封盘状态服务端全局锁定，客户端强制封盘拦截，无法突破购买
- 开奖号码服务端生成：开奖号码全程服务端随机生成，客户端无法预知、无法提前作弊
- 中奖奖金服务端核算：奖金平分、倍率计算全部服务端运算，杜绝自定义高额奖金外挂
